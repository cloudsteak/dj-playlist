DJ Playlist

    Üres a könyvtár

    Rekordboxban: File → Export Collection in xml format, majd az Adatok fülön importáld az XML-t.

    ⋯

      A szett üres

      A Könyvtárban a + gombbal adhatsz hozzá számokat, vagy építtess szettet automatikusan.

      Automatikus szettépítés

      BPM-ívet követ és harmonikus (Camelot) átmeneteket keres. Az eredmény új listába kerül.

      AI szettépítés (Claude)

      Szöveges kérés alapján az AI rendezi a sorrendet. Csak metaadat (előadó, cím, BPM, kulcs, műfaj, év) megy ki, fájlútvonal nem. API-kulcs kell az Adatok fülön. A fenti szűrők (műfaj, BPM, értékelés) itt is érvényesek.

      Kapcsolat a Mac-kel

      A háttérprogram figyeli a Rekordbox-forrást, és magától frissít. A listáid a Mac-en tárolódnak (így a telefonon és a gépen ugyanazok), és automatikusan Rekordbox-XML-be is kiíródnak.

      Rekordbox gyűjtemény importálása

      1. Mac-en, Rekordboxban: File → Export Collection in xml format.
      2. Vidd át a fájlt a telefonra (AirDrop / iCloud Drive).
      3. Itt válaszd ki az XML-t.

      Export és mentés

      Visszaolvasás Rekordboxba: Preferences → Advanced → Database → rekordbox xml → add meg az XML-t, majd a rekordbox xml fában jobb klikk a listán → Import Playlist.

      AI beállítások

      A kulcs csak ezen a készüléken van. Az app semmi mást nem küld sehova.
