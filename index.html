DJ Playlist

    Még nincs zene a könyvtárban.

    Rekordboxban: File → Export Collection in xml format, majd az Adatok fülön importáld az XML-t.

      A szett üres. A Könyvtár fülön a + gombbal adhatsz hozzá számokat, vagy használd az Auto / AI fület.

      Automatikus szettépítés

      A pool a Könyvtár összes trackje a megadott műfajjal. Az algoritmus BPM-ívet követ és harmonikus (Camelot) átmeneteket keres. Az eredmény új listába kerül.

      AI szettépítés (Claude)

      Szöveges kérés alapján az AI állítja össze a sorrendet. Csak metaadat (előadó, cím, BPM, kulcs, műfaj, év) megy ki az Anthropic API-nak, fájlútvonal nem. API-kulcs kell (Adatok fül).

      Rekordbox gyűjtemény importálása

      1. Mac-en, Rekordboxban: File → Export Collection in xml format.
      2. Vidd át a fájlt a telefonra (AirDrop / iCloud Drive / Fájlok).
      3. Itt válaszd ki az XML-t.

      Export

      Visszaolvasás Rekordboxba: Preferences → Advanced → Database → rekordbox xml → add meg az exportált XML-t, majd a bal oldali rekordbox xml fában jobb klikk a listán → Import Playlist.

      AI beállítások

      A kulcs csak ezen a készüléken, a böngésző helyi tárolójában van. Az app semmi mást nem küld sehova.
